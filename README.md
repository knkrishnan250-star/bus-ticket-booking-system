 Bus Ticket Booking System (Python)

A simple **console-based Bus Ticket Booking System** written in **Python**, suitable for 2nd-year Computer Science mini-projects.  
This project allows adding buses, listing available buses, viewing seat layout, booking tickets, cancelling bookings, and viewing passenger lists.  
All data is **saved persistently** using a JSON file (`buses.json`).



 Features

- Add new bus (source, destination, date, fare)
- List all buses with available seats
- 40-seat layout with booked/free status
- Book seat by seat number
- Cancel seat booking
- View passenger list for each bus
- JSON file storage (no database required)
- Clean, menu-driven interface
